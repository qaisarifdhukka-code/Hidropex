==================================================
1. PROJECT CONTEXT
==================================================

This is a new website for Hy-Tech Engineers Ltd., an industrial manufacturer of hydraulic/fluid connection fittings.

The current approved homepage design is already finalized.

IMPORTANT UI RULE:
The PRODUCT pages must follow the SAME visual language, design system, typography, spacing, colors, buttons, borders, cards, navigation behavior, and overall visual quality as the CURRENT NEW WEBSITE.

Do NOT copy the visual design of the old Hy-Tech website.

The old website is being used ONLY as a reference for:
- Product taxonomy
- Product hierarchy
- Product information
- Existing product structure
- Technical specifications
- Product navigation logic

The CURRENT NEW WEBSITE is the ONLY visual/UI reference.

The goal is:
Old website's PRODUCT INFORMATION STRUCTURE
+
New website's APPROVED UI DESIGN SYSTEM

==================================================
2. EXISTING PRODUCT STRUCTURE
==================================================

Hy-Tech currently has four main product families:

1. DIN Metric Fittings
2. JIC Tube Fittings
3. Conversion Fittings
4. O Ring Face Seal (ORFS) Fittings

We are NOT inventing new product families.

The new website should preserve the existing product catalogue structure.

Each main product family contains multiple series/sub-categories.

Example:

DIN Metric Fittings
    ├── Straight Series
    ├── Tee
    ├── Elbows
    ├── Ferrules
    ├── Nuts
    ├── Caps
    ├── Hollow Hex Plugs
    └── Weld Nipples

The exact existing product taxonomy should be preserved when implementing the prototype.

==================================================
3. PRODUCT PAGE HIERARCHY
==================================================

We will have three main levels:

LEVEL 1 — PRODUCT FAMILY / CATEGORY HUB

Example:
DIN Metric Fittings

This page allows users to browse the different series within that product family.

LEVEL 2 — PRODUCT GROUP

Example:
Straight Series
    → Equal Straight Couplings
    → Bulkhead Straight Couplings
    → Welding Connectors
    → etc.

This page displays the actual product groups belonging to that series.

LEVEL 3 — INDIVIDUAL PRODUCT

Example:
G-L-Straight Coupling

This is the technical product detail page.

The hierarchy must remain clear through breadcrumbs and navigation.

Example:

Products
→ DIN Metric Fittings
→ Straight Series
→ Equal Straight Couplings
→ G-L-Straight Coupling

==================================================

The product catalogue must work properly on:

- Tablet

- Drawer

Technical tables should become horizontally scrollable where necessary.

==================================================
12. SEO STRUCTURE
==================================================

The product architecture must be SEO-friendly.

Each important product family, product group, and individual product should have its own crawlable URL.

Use semantic HTML and proper heading hierarchy.

Each product page should support:

- Unique page title
- Unique meta description
- H1
- Logical H2/H3 hierarchy
- Descriptive URLs
- Breadcrumb structured data where appropriate
- Product structured data where the available information supports it
- Image alt text
- Canonical URLs

Do not sacrifice UX for SEO.

The product pages should be built as real HTML content, not as content hidden inside unnecessary JavaScript.

==================================================
13. PERFORMANCE
==================================================

This is an industrial catalogue website with potentially many product images and technical drawings.

The frontend should prioritize:

- Fast initial load
- Optimized images
- Lazy loading where appropriate
- Responsive images
- Minimal JavaScript
- Good Core Web Vitals
- Accessible HTML
- Avoid unnecessary client-side rendering
